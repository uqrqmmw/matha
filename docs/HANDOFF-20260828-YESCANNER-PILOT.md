## 已建立的安全界線

1. API 金鑰只從環境／受保護憑證讀取，不寫進 Git、manifest 或命令輸出。
2. 僅逐題、單執行緒呼叫；來源裁圖 SHA-256 不變且供應商輸出仍完整時，重建 QA 不再扣額度。
3. 固定使用 `data.base64img`，不使用服務另給的 cropped image。
4. 服務若回報旋轉或幾何校正直接拒絕；只有長寬比漂移不超過 0.5% 的等比例推論放大才可縮回原尺寸，供應商原圖仍永久保留。
5. 清理結果永遠是 `releaseAuthority:false`。每題仍須核對印刷文字／公式／圖線未損、手寫全除、無答案洩漏；答案配對與數學正確性是另一道獨立閘門。
