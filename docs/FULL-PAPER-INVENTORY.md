## 安全邊界

- 清冊只保存檔名、頁碼與 hash；題本、答案及詳解 PDF 不進公開 Git repo。
- 缺完整詳解不妨礙題本作為練習，但不能宣稱已完成隔日詳批閉環。
- 「未找到紀錄」不是「確定未看過」；每回第一次建立校準 run 前仍須確認。
